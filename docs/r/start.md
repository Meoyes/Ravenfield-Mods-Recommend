## 为什么会有这个网站？

其一：众所周知，Steam拥有完整的创意工坊内容，这是它的优点，也是缺点：<br>
&nbsp;&nbsp;&nbsp;&nbsp;优点：模组 ==全面== 、海量创作者齐聚<br>
&nbsp;&nbsp;&nbsp;&nbsp;缺点：种类繁多、内容 ==杂乱== <br>
其二：很多优质项目或许根本就不会登上 **最热门 最多人订阅** ，宣传这些模组是很有必要的，但是我们也没说不宣传最热门的模组😄

## 要注意什么？

本网站只提供内容，并不提供模组文件，如有需要请支持 **正版** ！
